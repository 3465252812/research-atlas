# 沿路线检索

采用实际当前日或用户截止日。每类生成问题词、机制词、别名和代表方法组合；补综述覆盖后文献，也回查遗漏的早期基础与桥接。

1. 分分类检索，保存原查询和范围。
2. 查基础/代表论文的前后向引用；引用存在不等于继承。
3. 查会议/期刊官方目录、论文页、arXiv 版本历史、项目页；核 v1，区分修订、录用、出版。
4. 查新机制、交叉分支及负面结果。可用已有文献库，不把连接器缺失作为停止本地整理的理由。
5. 新记录去重、提方法，写纳入理由、existing/new_branch/bridge、关联方法和核验状态。

日志最少 date/channel/query/scope/hits/included/excluded/failures。保留失败与替代渠道。说明未覆盖目录、年份、语言和数据库，有限检索不得宣称全领域穷尽。

无网络则继续本地资料，明确缺失的新文献搜索/URL复核，不伪造访问日志和最新结论。脚本负责转换，Codex 负责实际阅读、分类和证据判断。
