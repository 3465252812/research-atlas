# 原型分析与通用输出

## 实际原型

项目没有请求中简写的 reference 路径，使用用户明确提供的增强版附件。完整 JSON 程序解析，CSS/DOM及约3.4万字符脚本逐段检查：493方法、21分类、464全域边、5综述；research 有2组9路线、250成员、341专题边和250日期审计。methods 混合论文/方法，groups 泳道，edges 方法引用，surveys 溯源，research 专题。

原时间分段2020–2026、SLAM固定组、九路线及近期年份为领域硬编码。通用模板去掉这些常量，原型记录只存在回归数据；旧待核关系不提升状态。

## 保留视觉与交互

灰蓝底、白面板、蓝强调、紧凑字体、分类侧栏、三/二/单列卡片、24条分页、右详情、明暗主题、响应式及打印。两核心页签：合集和演进图。

合集：一二级分类和辅助归属筛选，名称/论文/作者/机制搜索、年份、排序、代表标记、分页/空状态/重置、详情弹窗、图定位、当前数据导出。详情含完整元数据、两个日期、问题、机制、贡献、价值、场景、局限、模块、分类依据、来源及核验状态。

演进：横轴动态年份，未知日期单独分箱，年内按日期排序；分箱不是连续精确日期刻度。纵轴主分类泳道，辅助归属用于筛选，避免重复节点。首次打开和重置均展示全部收录方法，不自动生成精选主线。支持方向/关系筛选、搜索定位、节点/边详情、前驱后继/借鉴/theme、高亮邻居、缩放/Ctrl滚轮/拖动/适宽/全屏/SVG。direct 蓝实箭头，extension 绿虚箭头，borrow 棕点划箭头，theme 灰点线无箭头。推断与待核在边提示、详情及节点状态明确展示。

## 通用数据驱动

canonical JSON 唯一权威；build 融合 papers/methods 为展示视图，保留 canonical。内嵌 application/json，无 fetch/CDN；JSON 中小于号转义防止闭合script，文本 HTML 转义，链接仅http/https。

领域名称、分类、统计数量、年份范围和核验状态以当前项目数据为准。固定文案只解释阅读方式，不默认宣称日期已逐篇核验或文献收录穷尽；具体日期来源、关系证据及待核状态在方法或连线详情中说明。

专题视图由 research_tracks 配置，支持多组路线、跨归属、时间范围和日期CSV；无配置时隐藏入口。专题成员和关系引用现有数据，可与原合集同时浏览。兼容器读取外部 --profile，将旧专题范围转为配置，通用模板不含领域名或固定年份。

SVG 内嵌样式和主题色，去交互命中层和临时高亮。当前合集导出有效 canonical 子集，能重建。

模板不自动提取PDF、检索、推断机制；数千节点需进一步性能评估，不能承诺无限规模。全屏失败有提示，无JS有提示。
