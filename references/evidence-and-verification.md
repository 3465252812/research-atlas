# 证据标准

区分原始全文、摘要、综述转述、出版索引元数据及旧库导入，记录实际阅读范围。PDF 文件页与印刷页分开，网页记章节和锚点。来源数量不替代质量。

标题、作者、标识、状态、首次公开/正式发表日期分别核验；不推定共同一作、通讯作者、单位。不从 arXiv 编号猜日，不用修订日冒充首次公开。精度不足保留年/月，冲突保留各方记录和选取理由。

机制、贡献、价值、场景、局限指向支持位置；AI 综合评价写 inference，不伪装作者原话。允许 null，缺口优于编造。

verified=关键论断有可追溯支持；partial=仅核部分；pending=未核；disputed=冲突未决。claim_basis、阅读层级、置信度、状态独立。

以上为数据与核验报告的记录要求。HTML 默认展示可读的论文信息和去重后的综述引用，不逐项堆放未知字段、内部导入代码或原始审计 JSON。关系推断在连线详情中简明注明；展示精简不改变证据记录或核验结论。

URL 语法通过不等于可达，实际访问记录日期/响应/跳转/最终目标。403/限流不等于论文不存在，尝试官方替代并待核。未访问不可声称有效。

旧 HTML audit/evidence 原样留 legacy，导入默认 pending，不表示重新阅读。用户认可图谱也不升级证据。报告区分已核事实/AI推断/待核/冲突，保存真实用户确认，不能代填。
